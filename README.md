# Perfil3_StephanyDominguez

Aplicación móvil hecha con React Native y Expo SDK 57. Muestra los datos de la estudiante y un catálogo de planetas obtenido de la [Dragon Ball API](https://dragonball-api.com/api/planets), con filtro por planetas en pie y destruidos.

- **Carnet:** 20240611

## Tecnologías

- React Native + Expo SDK 57
- React Navigation (Native Stack)
- Custom hooks: `useRequest`, `usePlanets`, `useProfile`
- EAS Build

```bash
npm install
npx expo start
```
